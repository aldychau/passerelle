# Signaler une faille

N’ouvre pas d’issue publique pour une faille. Écris en privé à **security@example.com**.

**ADRESSE D’EXEMPLE À REMPLACER par le responsable avant publication.** Cette adresse ne permet pas de joindre le projet.

Décris le problème et les étapes pour le reproduire avec des données fictives. Ne joins jamais de clé Etsy, jeton, secret.key, base locale, archive de boutique ni donnée client. Indique la version utilisée. Le responsable te répondra par le même canal privé.
